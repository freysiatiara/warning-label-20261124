The safety warning label that should come printed on every human being — one line, 95 characters, funny first and plausible second:

> WARNING: This human is not waterproof, not microwave-safe, and definitely not a morning person.

It borrows the wording and rhythm of real printed handling instructions and lands the laugh in the last few words, on a truth every human recognises.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
